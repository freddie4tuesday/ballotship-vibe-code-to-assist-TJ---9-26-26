Ballotship inject library

An inject is a surprise handed to a team during the exercise. This page lists them all. Saving changes the deck immediately: the next game that starts uses it (games already under way keep the deck they began with). Every save is kept as a numbered version under History, and any version can be restored. Injects are played in this order, starting from the one marked Start.
